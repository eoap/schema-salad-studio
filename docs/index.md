# Schema Salad Studio

Schema Salad Studio **0.1.0** is the first public release of a VS Code visual editor for Schema Salad definitions. Create and edit type cards, connect references, and set typed defaults while keeping YAML as the source of truth.

![Schema Salad Studio visual editor](assets/screenshots/schema-salad-studio-preview.png)

## Choose your starting point

| Your goal | Documentation |
| --- | --- |
| Learn by building a small schema | [Tutorial: create your first schema](tutorials/first-schema.md) |
| Install the extension | [Install and open](how-to/install-and-open.md) |
| Make changes to an existing schema | [Edit on the canvas](how-to/edit-schema.md) |
| Configure a default value | [Set a field default](how-to/set-defaults.md) |
| Look up supported features and limits | [Schema support](reference/schema-support.md) and [field controls](reference/field-controls.md) |
| Understand the design | [The YAML document model](explanation/editor-model.md) and [save-time ordering](explanation/serialization.md) |
| Contribute | [Develop and package](how-to/develop.md) and [maintain the docs](how-to/documentation.md) |

The installed extension works offline and requires VS Code 1.90 or later. It provides local structural checks; full Schema Salad validation remains a separate part of your workflow.

All features described here belong to 0.1.0. See the [changelog](https://github.com/eoap/schema-salad-studio/blob/main/CHANGELOG.md) for release history.
